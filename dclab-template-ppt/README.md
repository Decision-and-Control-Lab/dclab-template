# Template PowerPoint — Decision & Control Lab

Due template PowerPoint, ognuno nella propria cartella:

| Cartella | Cosa è |
|---|---|
| [`ufficiale/`](ufficiale) | **Template ufficiale del laboratorio**, con schema diapositiva (slide master) proprio: loghi, piè di pagina e font già impostati a livello di master. **Usa questo per le presentazioni del laboratorio.** |
| [`semplice/`](semplice) | Versione più semplice, generata come equivalente PowerPoint del template beamer (`dclab-template-beamer`), utile se preferisci partire da slide già pronte invece che da uno schema vuoto. |

Le istruzioni dettagliate (come iniziare, come modificare loghi/piè di pagina, problemi comuni) sono nel README di ciascuna cartella.
